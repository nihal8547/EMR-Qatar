# WhatsApp messages through n8n + Evolution API

HMS never holds WhatsApp credentials. It POSTs a JSON event to n8n; n8n sends the message with the Evolution API.

## n8n (folder "Qatar HMS")
| Workflow | Webhook path | When |
|---|---|---|
| HMS - WhatsApp: Patient registered (welcome) | `/webhook/hms/patient-registered` | new patient saved |
| HMS - WhatsApp: Result ready | `/webhook/hms/result-ready` | lab validated / radiology report final / "📲 Send result" button |
| HMS - WhatsApp: Visit completed (thank you) | `/webhook/hms/visit-completed` | visit becomes Completed (all billed + paid) |
| HMS - WhatsApp: Send bill | `/webhook/hms/bill-send` | "📲 Send bill" button |

Each workflow: open the **Config** node, set `instance` (Evolution instance name, must be connected) and `secret` (same value as `N8N_WEBHOOK_SECRET`); open **Evolution API - send** and choose the Evolution apikey credential; then publish.

## HMS
- env: `N8N_WEBHOOK_SECRET` (required). Optional `PUBLIC_BASE_URL`, `N8N_WEBHOOK_BASE`, `NOTIFY_FILE_SECRET`.
- Settings (admin → settings): `n8n_enabled=true`, `n8n_webhook_base` (e.g. `https://n8n.webbea.qa/webhook/hms`), `public_base_url` (internet-reachable URL of this HMS: PDF links), `n8n_send_bill_on_complete`.
- Permission `notify.send` (Reception, Cashier, Lab, Radiology, Doctor, Manager, Admin).
- Patient field `whatsapp_ok` = opt-out. Qatar numbers: 8 digits get +974.
- PDFs (invoice, lab report, radiology report) are generated by HMS and served from signed, 7-day links `/api/public/f/<token>.pdf`.
- Automatic sends run once per event (deduplicated in integration_logs); buttons can re-send. `GET /api/notify/status` shows setup and the last 15 deliveries.
- Tests: `N8N_WEBHOOK_SECRET=testsecret node test/notify.js` (mock n8n; run on a fresh `db:reset:demo`).

## WhatsApp Connect (Admin → WhatsApp Connect)
Set the Evolution API URL, instance name and API key (or env `EVOLUTION_API_KEY`), press **Connect WhatsApp**, scan the QR from the centre phone (WhatsApp → Linked devices). The page shows live status, disconnect, a test message, and the n8n options (enable, webhook base, public URL). The API key is never shown again after saving. Permission: `whatsapp.manage` (admin). Keep the instance name the same as `instance` in the n8n workflows' Config node.

## Separate database
The HMS uses only its own database (`qatar_hms`, own compose project/volume/network). n8n must keep its own database. The HMS refuses to start, migrate or seed (and `db:reset` can never run) if `DATABASE_URL` points at a database that holds n8n tables or has "n8n" in its name.
